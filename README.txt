# AndroidFleet Play Store-style landing page

## Files
- `index.html` — page structure and content
- `styles.css` — responsive mobile-first styling
- `script.js` — install URL placeholder, 55 sample reviews, helpful vote buttons, and reviews toggle
- `assets/` — reserved for final app icon and screenshots

## Preview
Open `index.html` directly in a browser. No build tools or server required.

## Before publishing
1. In `script.js`, replace `YOUR_PACKAGE_NAME` with your real Google Play listing URL.
2. Replace sample app metrics and all 55 fictional demo reviews with genuine, verified information.
3. Replace CSS-made screenshot cards with actual app screenshots if desired.
4. Add real support and privacy details.
5. Upload the files to your hosting provider.

This is a Play Store-inspired landing page, not an official Google Play page. Ratings, review counts, and review entries are demo placeholders.
